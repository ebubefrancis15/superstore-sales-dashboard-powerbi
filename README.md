# Superstore Sales Dashboard (Power BI)

## Project Overview

This project analyzes sales performance using the Superstore Sales Dataset (2014–2017). An interactive Power BI dashboard was developed to identify business trends, monitor key performance indicators (KPIs), and support business decision-making.

---

## Objectives

- Analyze sales performance
- Measure profitability
- Identify high-performing regions
- Evaluate customer segments
- Discover profitable product categories
- Build an interactive dashboard

---

## Dataset

Dataset: Sample Superstore Sales Dataset

The dataset contains:

- Orders
- Customers
- Products
- Regions
- Sales
- Profit
- Discounts
- Shipping information

---

## Tools Used

- Microsoft Power BI
- DAX
- Data Modeling
- Data Visualization

---

## KPIs

- Total Sales
- Total Orders
- Total Profit
- Profit Margin

---

## Dashboard Features

- KPI Cards
- Sales Trend by Year
- Sales by Region
- Sales by Category
- Sales by Segment
- Profit by Sub-category
- Geographic Sales Map
- Interactive Filters

---

## Key Insights

- Sales increased steadily and peaked in 2017.
- The West region generated the highest sales.
- Technology was the highest-performing category.
- Consumer customers generated the largest share of revenue.
- Tables recorded an overall loss despite strong sales.
